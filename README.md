# API Errors

This package provides simple class structures representing the most common HTTP response codes. Classes follow a hierarchy originating with `Error` to support `instanceof` logic in error handlers. Each error implementation includes several fields that can be used to provide detailed error responses for nuanced operations. 

## Installation

To install this library, you may use any prominent package manager. For example, using `npm`, simply run the following command in your project directory: `npm install @yeppleinc/api-errors`
